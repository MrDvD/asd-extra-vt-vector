## Основная информация

Этот репозиторий — моя реализация динамического массива `vt::Vector` на языке C++. Проект сделан для глубокого погружения в то, как устроены структуры данных и язык C++.

## Особенности реализации

* **API как в `std::vector`:** Реализовано около 80% методов стандартного контейнера.
* **Итераторы:** Написаны свои итераторы, так что вектор дружит с Range-based for и стандартными алгоритмами STL.
* **Cтандарт С++23:** Активно используются новые особенности языка и шаблоны.
* **Надежность:** Учитывал безопасность исключений и не забывал про инкапсуляцию.

## Анализ производительности
### Метод банкира
Для оценки учетной стоимости операции `push_back` применен метод банкира, доказывающий амортизированную сложность $O(1)$.

### Асимптотика
Для каждого значимого метода в комментариях указана временная сложность.

## Сборка и требования
Проект поддерживает сборку через **CMake** и разделен на две цели: статическую/динамическую библиотеку и исполняемый файл с тестами.

**Требования:**
* Компилятор с поддержкой C++23.
* CMake.

**Инструкция по сборке:**
```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE="Debug"
cmake --build build
```

## Тестирование и качество кода
### Модульные и сравнительные тесты
Разработаны тесты на базе **GoogleTest**, проверяющие как типичные сценарии использования, так и крайние случаи. Проведено сравнение производительности с `std::vector`.

### Инструменты анализа
Для обеспечения надежности и чистоты кода используются:
* **ASan & UBSan:** Проверка корректности работы с памятью и отсутствия неопределенного поведения.
* **Clang-format & Clang-tidy:** Соблюдение единого стиля и статический анализ.
* **Perf & FlameGraph:** Профилирование CPU и памяти для поиска узких мест.
* **GitHub Actions:** Настроен CI для автоматической сборки и прохождения тестов.
